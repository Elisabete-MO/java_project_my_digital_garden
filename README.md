# 🌱 Meu Jardim Digital

Um projeto pessoal pensado para amantes de plantas que querem registrar, acompanhar e cuidar melhor do seu próprio jardim.

## ✨ Funcionalidades previstas

- 📸 Identificar plantas a partir de imagens com apoio de IA
- 🌿 Marcar plantas como "favoritas", "tenho", ou outras categorias
- 🖼️ Registrar fotos pessoais da planta ao longo do tempo (carrossel por datas)
- 📓 Adicionar anotações no estilo diário, vinculadas ou não a fotos
- 🌾 Informações úteis para cada planta (substrato ideal, tipo de adubo etc.)
- ⏰ Controle de adubação com histórico e sugestão da próxima adubação
- 🔔 Alarmes configuráveis para lembrar de cuidados futuros

## 🛠️ Tecnologias

- Java + Spring Boot
- Gradle
- Swagger para documentação da API
- Angular (frontend)
- Arquitetura de Microsserviços
- Inteligência Artificial para reconhecimento de plantas (a definir)
